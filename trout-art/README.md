# Species illustrations

Each species card on the Trout Map shows a generic trout until its own picture is here.

Name the file after the species id from `src/trout-species.js` (the first value on each line), for example `westslope-cutthroat.png` or `brook-trout.jpg`. PNG, JPG, WebP and SVG all work. A wide image, about 3:1, fits the card best.

Push to main and Vercel rebuilds the site with the new picture.
